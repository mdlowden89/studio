# **App Name**: Crossd

## Core Features:

- Moment Logging: Capture significant places and times.  Crossd intelligently logs when you cross paths with a potential match and will alert you giving you the option to match with that user if you saw them.  Logging the user's current location and recent locations using GPS to enable 'crossd paths' matching.
- Vibe Signal Engine: Our AI tool suggests compatible users based on shared vibe tags and location patterns, helping users find their perfect match.
- In-App Chat: Once matched, start a conversation securely within the app.  No need to share personal contact information prematurely, with verification features and video call options.
- Image Uploads: Allows users to upload images to their profile.
- Image Replace: Allows users to replace the current images on their app page.
- Swipe-based Matching: Implement a standard swiping interface for fallback matching when the location data is unavailable or insufficient. Re-use swiping gestures in the primary 'crossed paths' functionality.
- Profile Prompting: Profile prompts (like Hinge) to foster quality matches and spark meaningful conversations.
- Moments Memory Trail: Show users a timeline or heatmap of their visited places, allowing them to revisit potential 'moments'.

## Style Guidelines:

- Primary color: A vibrant magenta (#E70F72), injecting boldness and capturing the spark of missed connections.
- Background color: A very dark gray (#080808), setting an intimate and mysterious mood reminiscent of fleeting encounters in the night.
- Accent color: A white (#FFFFFF), applied strategically to draw attention to calls to action, ensuring ease of navigation and sparking user engagement.
- Clean, modern typography that ensures readability and feels approachable.
- Minimalist icons to represent locations, moments, and user interactions.
- Smooth transitions and subtle animations when revealing matches or revisiting 'Moments'. Use animations to signal to the user when two 'crossed paths' selections result in a match.
